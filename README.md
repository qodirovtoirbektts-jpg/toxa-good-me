# Good Me (Toxa) — 100% Organic Wellness & Adaptogenic Elixirs UI

A state-of-the-art, responsive wellness and organic superfood e-commerce website UI crafted with clean aesthetics, interactive quiz configurator, slide-out shopping cart drawer, and modern glassmorphism.

## ✨ Features
- **Modern Botanical Aesthetic**: Curated color palette (Botanical Emerald, Oat Milk Cream, Coral Peach) with Playfair Display and Plus Jakarta Sans typography.
- **Interactive Daily Elixir Quiz**: 3-step recommendation engine matching user goals with the right adaptogenic formula.
- **Dynamic Slide-out Cart Drawer**: Live subtotal recalculations, quantity steppers, and interactive toast notifications.
- **Category Filter Tabs**: Instant filtering between Energy, Skin Radiance, Sleep, and Gut Cleanse.
- **Clinical Comparison Table**: Highlighting pure dual-extraction standards over generic synthetic powders.
- **100% Responsive Design**: Optimized for desktops, tablets, and smartphones.
